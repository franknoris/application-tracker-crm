# Application Tracker CRM

A web app to manage an internship and scholarship search: organizations, contacts, applications with pipeline stages and deadlines, interaction logs, and tasks.

## Stack

- Backend: FastAPI (Python), SQLAlchemy 2.x, Pydantic v2, PostgreSQL
- Frontend: React + TypeScript (Vite), Tailwind CSS + shadcn/ui
- Infra: Docker + Docker Compose, GitHub Actions
